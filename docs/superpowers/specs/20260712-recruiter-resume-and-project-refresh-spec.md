# 招聘向个人网站与简历同步更新规格

## 背景

个人网站现有内容将项目涉及的全部技术栈与个人熟练技能混在一起，邮箱仍为旧 Gmail，首屏主 CTA 也不是用户确认的“下载简历”。用户当前明确掌握 Java、C、Python；轻灵、轻·棋局和 MiniMax 多模态控制台均包含大量 AI 协作。

## 目标

1. 面向招聘者展示真实、可核验的技能与项目角色。
2. 首屏唯一主 CTA 为下载简历。
3. 更新邮箱为 2293822701@qq.com。
4. 将轻灵、轻·棋局、MiniMax 多模态控制台作为三项代表项目。
5. 明确项目采用的技术不等于个人已熟练掌握，项目角色统一体现 AI 协作。
6. 将可导入 MagicCV 的简历作为网站静态资源，并在简历中加入经验证的个人网站网址。

## 内容边界

- 个人技能只写 Java、C、Python及可证明的调试、测试、AI协作能力。
- 不使用“独立实现全部技术栈”“全栈专家”“生产级”等无法由现有证据充分支持的表述。
- 项目说明聚焦需求提出、方案取舍、AI协作、调试、验证与迭代。
- MiniMax 项目依据本地 C:/Users/Lenovo/projects/minimax-photo-agent 的 README、提交记录与远端地址更新。

## 交互与视觉

- 受众：招聘者。
- 气质：年轻、有活力、诚实。
- 主 CTA：下载简历。
- 保留现有视觉系统与整体布局，只做内容和 CTA 的窄调整。
- 下载链接必须指向站内静态 JSON 资源并带 download 语义。
- 关键桌面端与移动端视口均需验证 CTA 可见、项目顺序和内容不溢出。

## 验收标准

- 首页和关于页显示新邮箱。
- 首页首屏主按钮为“下载简历”，次级动作降级为查看项目。
- 三项代表项目按轻·棋局、轻灵、MiniMax 展示，均标注 AI 协作边界。
- 网站技能列表不再将 TypeScript、JavaScript、前端框架列为个人技能。
- npm test、npm run lint、npm run build 通过。
- 375px 与 1440px 视口完成新鲜视觉验证。
- 个人网站生产网址在线可达后写入 MagicCV 简历。
